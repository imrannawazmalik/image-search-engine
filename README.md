# Image Search Engine

A modern and responsive **Image Search Engine** built using **HTML, CSS, and JavaScript**.

This project uses the **Unsplash API** to search for images dynamically based on the user's search query and displays the results in a responsive image gallery.

## ✨ Features

* 🔍 Search images dynamically
* 🖼️ Display multiple image results
* 📱 Fully responsive design
* ⚡ Fast API-based image searching
* 🎨 Clean and simple user interface
* 📐 Responsive image grid
* ❌ Empty-search validation
* 🌐 Unsplash API integration

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Unsplash API
* Font Awesome

## 🚀 How to Run

1. Clone this repository.
2. Open the project folder.
3. Add your Unsplash API credentials securely.
4. Open `index.html` in your browser.
